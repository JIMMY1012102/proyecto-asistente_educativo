# Guía de contribución

## Ramas

- `main`: versión estable.
- `develop`: rama de integración.
- `feature-nombre`: cambios específicos.

## Flujo

1. Crear una rama desde `develop`.
2. Realizar cambios pequeños y trazables.
3. Usar Conventional Commits en español.
4. Solicitar revisión de otro integrante.
5. Integrar el cambio a `develop`.

## Commits

Ejemplos:

- `docs: agregar arquitectura C4`
- `feat: agregar autenticacion`
- `fix: corregir validacion de roles`

## Revisión

Todo cambio que llegue a `develop` debe ser revisado por al menos otro integrante del equipo.
