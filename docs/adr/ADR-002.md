# ADR-002 — Base de datos y persistencia

**Estado:** Aceptado  
**Fecha:** 2026-10-09

## Contexto

R2, R3 y R11 requieren procesamiento controlado de resultados, clasificación de errores y protección de datos.

La sesión establece MySQL/MariaDB sobre XAMPP como base de datos y una única fuente de verdad.

## Alternativas evaluadas

### SQLite
Adecuada para pruebas simples, pero no coincide con la infraestructura definida para esta sesión.

### MySQL/MariaDB de XAMPP
Permite trabajar con el entorno requerido y administrar el esquema mediante phpMyAdmin.

### Almacenamiento duplicado
Se descarta porque generaría más de una fuente de verdad.

## Decisión

Se utilizará **MySQL/MariaDB de XAMPP** como única fuente de verdad.

- Collation: `utf8mb4_unicode_ci`.
- Motor: InnoDB.
- Claves foráneas declaradas.
- Índices sobre claves foráneas y campos de búsqueda.
- Secretos fuera del repositorio.

La conexión futura con MCP quedará documentada para la Unidad 3, sin implementarla esta semana.

## Consecuencias

- El esquema se mantendrá en `database/schema.sql`.
- La base será verificada mediante phpMyAdmin.
- No se duplicarán datos en otra base persistente.

## Deuda aceptada

Credenciales, puertos y configuración final quedan **[VERIFICAR EN SEMANA 7]**.

## Criterio de reversión

Si el esquema no puede crearse correctamente en MariaDB/MySQL de XAMPP o fallan las relaciones, se revisará el diseño antes de implementar funcionalidades.
